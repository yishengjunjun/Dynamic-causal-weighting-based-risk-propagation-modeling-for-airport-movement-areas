# 实验协议与评价定义

## 数据域和训练边界

输入为观测负载 `history[B,H,N]`、下一时刻观测 `target[B,N]`，以及可选的连续未来观测 `future_loads[B,F,N]`。`target` 必须与 `future_loads[:,0]` 一致。转移训练使用每一实际未来步对应的观测作为奖励标签；缺少连续未来观测时不得启动该模式。精细化训练只使用下一时刻标签。

一个事件可以提供多个窗口。样本通过唯一 `sample_ids` 标识，`event_ids` 表示事件分组。同一事件的全部窗口必须具有一致年份和机场，且全部归属同一个训练、验证或测试折。模型、网络和容量拟合不读取测试标签。

`enabled_protocols` 控制实验划分。默认仅启用 `primary`，因此单年份、单机场数据可执行主实验。其他协议必须明确启用并提供覆盖所需的数据；启用后出现空训练或测试集会报错，不能改用其他年份或机场。

| 协议 | 定义 |
|---|---|
| `primary` | 按年份对事件组分层，使用 `stratified_train_fraction`，逐随机种子训练 |
| `additional_fraction` | 依次执行 `additional_train_fractions` 中预先指定的训练比例 |
| `rolling` | 测试年为 y，训练范围为 y−12 到 y−4，验证范围为 y−3 到 y−1，测试范围为 y |
| `airport` | `airport_holdout` 为测试机场，其余机场为训练域 |
| `count` | 按随机种子打乱唯一事件组，取 `printed_train_count` 个事件作为训练域 |

验证折只报告预测误差，当前流程不使用验证或测试结果自动搜索参数。所有启用模型的结果均保留。

## 每折网络和容量

每个协议、每个主实验随机种子都独立调用 `network.prepare_fold_data`：

1. 只用训练样本计算灰关联等级、出现率和变异性。
2. 根据灰关联阈值和活动因子规则筛选节点；同步裁剪历史、目标和未来观测的节点轴。
3. 只用训练事件对应的审核因果链统计边，并进行链内顺序置换检验及 FDR 校正；显式专家边具有独立审核记录。
4. 在筛选后的图上重算容量和节点属性。
5. 对验证和测试样本应用同一节点集合及已拟合参数。

`capacity_mode=grey_topology` 使用公式 5–7；`capacity_normalization=unit_mean` 将容量均值归一到 1，适用于已定义的无量纲负载。`capacity_mode=train_quantile` 使用训练历史的 `train_capacity_quantile` 分位数和正值下限，保留观测负载单位。两种容量模式不得混用评价单位。

`network_mode=external_fixed` 接收独立的、有来源说明的先验网络及容量。节点选择仍在训练域进行，外部矩阵只裁剪相应子图，不从测试数据重新估计。输入必须提供 `metadata.network_source`。

`networks/` 保存训练事件清单、因子选择、节点原始位置、边频率、p/q 值、容量、阻抗标记和网络统计。筛选后不足两个节点的敏感性条件记录为 `not_trainable`，不以强制保留若干节点替代筛选规则。

## 预测模型与消融

主对照包含 DWPM、NDWPM、DBN、VAR 和 T-GNN，`model_names` 可指定子集，且始终包含 DWPM。所有同折模型使用相同的训练样本、测试样本、节点集合和评价容量。DBN 的状态概率单独计算 Brier 分数；其他模型的负载容量比不作为事故概率。

消融分别训练 DWPM、移除强化学习、再移除注意力，以及静态权重模型。各模型结构与训练优化由 `models.py`、`baselines.py` 和完整配置确定。训练模式、监督预热轮数、卷积核、层数、隐层宽度、学习率和随机种子均写入结果。

## 指标

设预测负载为 p，观测负载为 y，训练折容量为 C。样本节点平均归一化误差为 `mean((p/C−y/C)^2)`，MAE 为相应绝对误差。`event_mean_mse_normalized` 先在事件内部对窗口和节点平均，再对唯一事件平均，避免多窗口事件自动获得更大权重。

节点失效标记为 `load >= C`。节点准确率按样本和节点计算；事件失效标记为该事件任一窗口、任一所选节点失效。事件准确率按唯一事件计算。风险分数为 `clip(p/C,0,1)`，分箱边界为 `<0.5`、`[0.5,0.7]`、`(0.7,0.85]`、`>0.85`。高风险事件标记是该事件最大预测分数超过 0.85；标记频率与分类准确率分开报告。

每折样本量、事件量、节点数和边数都随指标保存。不同节点集合的全节点准确率不直接当作相同预测任务比较。

## 灰关联阈值敏感性

`grey_thresholds` 中每个阈值独立筛选因子、重建图与容量并重新训练，实际预测节点数 N 随阈值变化。每个条件同时保存：

- 当前子图上的全节点指标和逐事件结果。
- 全部可训练阈值条件与主训练折共同节点上的指标，统一使用主训练折对应节点的容量。
- 实际节点清单、N、边数、结构指纹及网络数值指纹。

可选的 `grey_quantile_diagnostics` 只用训练域等级的 25%、50%、75% 分位点生成附加筛选条件。共同节点交集包含这些附加条件。没有共同节点时不生成共同节点误差。阈值未改变节点与边结构时记录 `grey_sweep_degenerate`，不能据此宣称结构鲁棒。

## 动态攻击与干预

压力历史按已保存的主测试样本索引取前 `stress_history_count` 条，仅使用截至末次观测的历史。每条历史依次攻击每一个节点，将受攻击节点末次负载设置为 `max(观测负载,C×(1+10⁻⁶))`。所有策略使用相同攻击集合。

动态模式每周期执行：当前历史计算权重 → 节点关系门控与同步物理传播 → 干预 → 将预测负载追加到历史。未来观测不参与权重计算、排序或压力传播。冻结模式固定使用完整训练折平均权重，其他条件保持一致。两类模式分别保存全部结果。

控制预算为 `ceil(control_fraction×N)`，干预强度为 `control_reduction`。干预仅减少所选目标节点的正向新增负载，保留阻抗造成的负向恢复量。

| 策略 | 排序或抽样 |
|---|---|
| 无干预 | 相同攻击下不施加控制 |
| 节点度 | 入度与出度之和降序，输入节点顺序处理并列 |
| NRI 与负载比复合 | 优先选择有定义的 NRI，预算不足时按负载容量比降序补齐；记录补齐节点及次数 |
| 随机 | 固定种子下无放回抽取相同数量节点；每次抽样应用于完整攻击集合 |

`control_rank_mode=fixed` 在攻击起点选择复合策略节点；`adaptive` 每周期根据当前负载重新排序。随机策略按配置执行全部 `random_control_repetitions` 次，保存抽样指纹，动态与冻结对照复用同一种子和节点集合。最终收益为相同模式无干预最终平均 NDI 的相对下降；分母为零时收益记为空值。

节点幅度扰动另按 `perturbation_levels` 独立执行。结果同时保留相对初始总负载的变化，以及相对于同历史无扰动闭环传播的额外增量；后者用于成对扰动影响图。NRI 仅对有定义的历史求均值并保存有效数量。SRI 的非有限历史数量另行保存；JSON 非有限数值序列化为空值，不替换成零。无边图的传播攻击和干预标为 `not_applicable`。

## 容量与 η 敏感性

容量预测敏感性逐条件重新训练，模型容量乘以 `capacity_scales`，但评价容量、标签和归一化单位均保持主训练折名义容量不变。容量传播敏感性保持预测权重模型固定，改变物理传播容量并计算 NDI。两者分别输出。

η 是拓扑压力场景初始负载的系数；`eta_scales` 只改变该初始状态。历史观测预测不使用 η，因此不生成名为 η 预测准确率的结果。

## 轨迹与续训

`dynamic_rollout.json` 保存首个主测试样本的闭环负载和权重。只有提供真实观测的未来步计算误差；观测标签不追加到预测历史。推理计时包含一个样本的权重计算及一步物理传播，在本机 CPU 进行。

DWPM 和 T-GNN 保存可恢复训练检查点，包括模型参数、优化器、训练阶段、随机状态、训练数组及配置指纹。`resume_checkpoints` 将 `协议_seed随机种子_模型` 映射到检查点路径。`epochs` 表示本次增加的训练轮数，`warmup_epochs` 表示预热总轮数；续训不重复已完成的预热。实验报告保存累计曲线、累计训练及预热轮数。

结果配置指纹排除本次增加的 `epochs` 和检查点路径映射，其他实验、模型和数据定义必须一致。数据或配置不匹配的检查点拒绝接续。源码审阅包不包含私有数据、检查点或实测输出。
