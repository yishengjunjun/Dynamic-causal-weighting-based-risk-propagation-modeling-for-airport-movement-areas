# 公式与实现映射

矩阵统一采用 `[源节点,目标节点]`。公式的操作定义、计算边界及模型约束如下；实验通过配置保存全部数值设置。

| 公式 | 实现 | 计算定义 |
|---|---|---|
| 1–2 | core.grey_relational | 因子对 1 的均方根偏差，rho=1/(1+平均偏差) |
| 3–4 | core.grey_relational | 差值极值取整个训练矩阵；样本均值为关联度；严格 r>threshold |
| 5–7 | core.capacities | 有向最短路径条数比拓扑项，加归一灰关联保护项 |
| 8 | core.initial_load | eta×容量×(入度+1)/(入度+出度+2) |
| 9–11 | core.propagate_step | 激活源×边权×目标容量，旧负载同步更新，L≥C 激活 |
| 12 | core.impedance_theta | 稳定形式 sigmoid(-L)-exp(-C)×sigmoid(L)，保留过载负值 |
| 13 | models.CausalConv1d | 左因果膨胀卷积，W[k] 对应 x[t-d×k] |
| 14–16 | models.CCRLModel._attention | 查询／键投影，出边掩码后按目标轴归一化 |
| 17 | models.CCRLModel | 注意力×最后两步已观测目标增量／前一源负载；负增量归零；非边为零 |
| 18–19 | models.CCRLModel | 固定节点顺序展开边权状态；Normal 策略采样边权增量，执行权重限制在配置区间 |
| 20 | models.CCRLModel.fit | 负的节点负载误差平方和，真值仅用于训练奖励 |
| 21–22 | models.CCRLModel.fit | 一步 TD，终止状态不自举，Critic 目标停止梯度 |
| 23 | models.CCRLModel.fit | 实际采样动作联合 log-probability×停止梯度 TD 优势 |
| 24 | core.nri | phi 取直接后继，d 取有向最短距离，保留原式 Dout_i+1 |
| 25 | core.sri | 两项按乘积解释；删除失效节点相关边，比较最短路径条数，N 保持原图规模 |
| 26 | core.ndi | 有向归一化介数；过载及等容量按 2×b_i×L_i 累加 |

## 数值及图约定

灰关联输入为 `[训练样本,候选因子]` 和 `[训练样本]` 参考序列。全部差值为零时系数为 1，非有限输入拒绝。低层函数不隐式归一化输入；训练域因子选择另外排除从未出现及配置指定的常量列。

式 6 对可达有序节点对统计全部等长最短路径，经过节点时排除端点。它是路径条数总和的比，与式 26 逐对路径份额求和的介数不同。无可达路径时拓扑容量项为零。

`grey_topology` 在式 5–7 后按配置作正下限、整体尺度及可选均值归一，单位为无量纲。`train_quantile` 是另一种容量定义，使用训练历史的节点分位数保留输入单位。两种定义在实验配置及网络审计中分别记录。

传播按同步旧状态执行，已激活源每周期均可传播。式 12 的 Theta 在 L>C 时为负，可放大增量。低层传播保留有符号权重；可学习模型的边权限制由 `max_weight` 明确声明。逐步输出若非有限则报告失败，不靠目标数字修正。

互斥、共现、累积及上下文关系通过统一算子进入 CCRL、静态模型、T-GNN 和动态压力实验；定义见[模型说明](MODEL.md)。空关系配置保持式 9–12。表 2 上下文先按区间查表，再加权聚合，与式 12 的基础阻抗组合。

## 指标边界

NRI 在无后继或 L≥C 时无定义，返回 NaN。复合干预以负载容量比补齐未定义的 NRI 排名，单独命名并记录所用节点；不把缺值当零风险。

SRI 在原图无路径时为 NaN，全部节点失效时取正无穷。部分失效后没有剩余路径时可能为零，须联合失效节点数解释。NDI 在等容量处取激活侧边界，与 L≥C 的激活约定一致。

JSON 将非有限指标保存为 null，另外记录实验状态与原因；不把 null 改成有利分数。

测试入口为 `python -m pytest -q`；测试记录见 [software_validation.json](../review/software_validation.json)。
